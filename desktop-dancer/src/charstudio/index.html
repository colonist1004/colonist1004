캐릭터 만들기

캐릭터 그림 한 장으로 춤추는 3D 캐릭터(VRM)를 만듭니다.

처음 한 번만: 준비하기

변환 도구에 Python이 필요한데 이 PC에서 찾지 못했습니다. Python 3.12를 설치할 때 “Add python.exe to PATH”를 꼭 체크하고, 끝나면 다시 확인을 누르세요.

필요한 도구(Python 3.12, MediaPipe 등)를 자동으로 내려받아 앱 전용 폴더에 설치합니다. Python을 따로 설치할 필요는 없어요. 처음 한 번, 수백 MB라 몇 분 걸릴 수 있습니다.

    2 그림을 3D로 만들기 — 방법 고르기
    
        
    
          
    
            내 PC 그래픽카드로 만들기 (TripoSG / TripoSR) AMD·NVIDIA · 무료 · 오프라인
            
    그래픽카드 확인 중…
    
            
    
              
    
                처음 한 번 준비가 필요합니다. 그래픽카드용 PyTorch와 생성 AI 프로그램을 앱 전용 폴더에 설치합니다
                (수 GB, 10~30분). 모델 파일(수 GB)은 처음 만들 때 내려받습니다.
              
    
              
    AMD: 그래픽 드라이버 Adrenalin 26.2.2 이상이 필요합니다 (AMD 공식 PyTorch for Windows, RX 7000·9000 시리즈).
    
              
    
                
                
              
    
              
    
            
    
            
    
              
    
                모델
                
    
                  
                  
                
    
                품질
                
    
                  
                  
                
    
                그림 종류
                
              
    
              
    
                
                
                
              
    
              
    
                결과는 3번으로 이어져 뼈대·흔들림까지 자동으로 넣습니다. TripoSG는 그림의 색을 모델에 입히고(뒷면은 근사),
                TripoSR은 색까지 스스로 만듭니다. 두 모델 모두 MIT 라이선스입니다 (TripoSG 저장소에는 일부 코드가 Tencent Hunyuan
                계열에서 왔다는 안내가 있습니다).
              
    
            
    
          
    
          
    
            A. 무료 웹 생성기 + 내 PC 자동 리깅 그래픽카드 상관없음
            
      
              
    1. 아래 사이트 중 하나에서 1번의 그림을 올려 3D 모델을 만들고 GLB로 내려받습니다.
                
      
                  
                  
                
      
              
      2. 
              
    2. 내려받은 GLB를 3번 칸에 넣으면, 뼈대는 이 PC에서 자동으로 넣습니다 (AMD·인텔 그래픽도 OK, 약 15초).
      3. 
            
    
            
    무료 등급의 생성 횟수와 결과물 이용 조건(상업 이용, 저작자 표시 등)은 각 사이트에서 확인하세요.
    
          
    
          
    
            B. 클라우드 GPU (TRELLIS + UniRig) 오픈소스 · NVIDIA GPU 대여
            
    
              그림→3D(TRELLIS)와 뼈대(UniRig) AI를 RunPod 같은 클라우드의 NVIDIA GPU(VRAM 16GB 이상)에서 돌립니다.
              시간당 수백 원, 첫 실행은 설치 때문에 20~30분, 이후 캐릭터당 3~5분.
            
    
            
      
              
    1. GPU 인스턴스를 시작합니다 (예: RunPod → PyTorch 템플릿).
      2. 
              
    2. 
                아래 버튼으로 연 pipeline 폴더 전체와 1번의 그림을 인스턴스에 올립니다.
                
      
              
      3. 
              
    3. 
                인스턴스의 터미널에서 이 명령을 실행합니다.
                
      bash pipeline/cloud/run_character.sh 그림파일.png
      
              
      4. 
              
    4. 끝나면 생기는 .vrm(또는 .rigged.glb)을 내려받아 3번 칸에 넣습니다.
      5. 
            
    
            
    TRELLIS와 UniRig는 MIT 라이선스입니다.
    
          
    
          
    
            C. VRoid Studio로 직접 만들기 슬라이더로 세밀한 디자인 · 무료
            
    
              얼굴·눈·머리카락·옷을 슬라이더와 브러시로 직접 디자인하는 무료 프로그램입니다 (코이카츠처럼 세밀하게 조정 가능,
              AMD 그래픽 OK). 만든 캐릭터를 VRM으로 내보내기한 뒤 3번 칸에 넣으면 됩니다.
