# Desktop Dancer

Windows 작업표시줄 위에서 3D 캐릭터(VRM)가 춤(VRMA)을 추는 데스크탑 앱입니다.
현재 단계는 **Part C MVP**입니다. 샘플 캐릭터와 샘플 춤이 작업표시줄 위에서 반복 재생됩니다.
영상에서 춤을 추출하는 Part B와 그림 한 장으로 캐릭터를 만드는 Part A(`pipeline/`)도 들어 있습니다. 자세한 내용은 [docs/spec.md](docs/spec.md)를 참고하세요.

## 받기 (Windows)

GitHub 저장소 **Actions → Build Desktop Dancer (Windows)** 에서 최근 실행을 엽니다.
**Artifacts** 의 `desktop-dancer-windows` 를 내려받으면 설치 프로그램이 들어 있습니다.

- `DesktopDancer-…-setup.exe` — 설치 프로그램 (시작 메뉴 등록, 제거 가능)

코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜹니다. **추가 정보 → 실행**을 누르세요.

## 사용법

- 실행하면 화면 오른쪽 아래, 작업표시줄 바로 위에서 캐릭터가 춤을 춥니다.
- 캐릭터가 아닌 빈 영역은 클릭이 뒤의 창으로 그대로 전달됩니다.
- 캐릭터를 잡고 끌면 **어디로든** 옮길 수 있습니다. 작업표시줄 가까이에 놓으면 다시 작업표시줄 위에 섭니다.
- 캐릭터 위에서 **Ctrl + 마우스 휠**을 돌리면 크기가 바뀝니다.
- 트레이 메뉴 **위치·크기 자세히 조정…** 에서 크기와 위치를 정밀하게 맞출 수 있습니다.
  - 크기: **25%~1600%**
  - 가로 위치·높이: 픽셀 단위 숫자 입력, 1px/10px/100px 이동 버튼, 왼쪽·가운데·오른쪽 버튼
  - **상체만 보이기**: 캐릭터를 작업표시줄 아래로 내려 상체만 보이게 합니다. 높이를 음수로 넣거나 아래로 끌어도 됩니다.
  - **작업표시줄 뒤로**: 켜면 작업표시줄보다 아래로 내려간 부분이 작업표시줄 위에 그려지지 않고 그 뒤에 숨은 것처럼 가려집니다. 크게 키우거나 아래로 내렸을 때 쓰세요. 위치·크기 창의 체크 상자나 트레이 메뉴 **크기**에서 켭니다.
  - 화면 밖으로 밀 수 있습니다. 좌우는 몸의 절반 정도, 아래로는 머리와 어깨까지 보이게 남깁니다.
  - 화면보다 크게 키우면 캐릭터 크기는 그대로이고 화면 밖으로 나가는 부분이 잘려 보입니다.
- **트레이 아이콘**
  - 클릭: 보이기/숨기기
  - 우클릭 메뉴: 캐릭터·춤 변경, VRM/VRMA 파일 추가, 크기(50~1600%), 위치·크기 자세히 조정, 모니터, 속도, FPS 제한, 자동 실행, 위치 초기화, 라이브러리 폴더 열기, 종료
- **캐릭터 → 샘플 캐릭터 내려받기 (Seed-san)** 를 누르면 VRM 컨소시엄의 샘플 캐릭터를 받습니다. 라이선스는 VRM Public License 1.0입니다.
- 내가 가진 `.vrm` / `.vrma` 파일은 **파일 추가…** 로 넣을 수 있습니다. **라이브러리 폴더 열기** 로 연 폴더에 직접 복사해도 됩니다. 폴더 위치는 `%APPDATA%\desktop-dancer\library` 입니다.

## 처음 한 번: 준비

춤 만들기나 캐릭터 만들기 창을 처음 열면 **설치 시작** 버튼이 나옵니다. 누르면 필요한 도구가 앱 전용 폴더(`%APPDATA%\desktop-dancer`)에 자동으로 설치됩니다.

- Python도 함께 내려받기 때문에 **따로 설치할 필요가 없습니다.**
- 처음 한 번 수백 MB를 내려받으며, 몇 분 걸립니다.

## 내 춤 영상으로 모션 만들기

트레이 메뉴에서 **춤 만들기 (영상에서)…** 를 누르세요.

1. **영상 넣기**
   - 영상을 끌어 놓거나 URL을 넣고, **지금 위치로** 버튼으로 시작과 끝을 정합니다.
   - 유튜브 URL을 쓰려면 위의 준비 단계로 설치된 도구가 필요합니다.
2. **인식 방식 고르기**
   - **정확하게 (RTMW3D)**: 기본값. 그래픽카드를 씁니다(DirectML이라 AMD·인텔·NVIDIA 모두 가능). 처음 한 번 모델 약 300MB를 내려받으며, 안 되면 자동으로 ‘보통’으로 바뀝니다.
   - **보통 / 빠르게 (MediaPipe)**: 가볍게 CPU로 인식합니다.
3. **더 정확하게 만들고 싶을 때**
   - Rokoko Vision(카메라 1대 무료), Plask, DeepMotion, QuickMagic 같은 웹 모캡 서비스에서 같은 영상을 처리해 **BVH**로 받습니다.
   - 받은 BVH를 같은 칸에 넣으면 그대로 변환됩니다. 창 안의 안내에 각 서비스 바로가기가 있습니다.
   - 다리가 화면 밖으로 나가거나 가려진 구간에서는 다리를 억지로 추측하지 않고 **서 있는 자세**로 둡니다. 상반신만 나오는 영상도 쓸 수 있습니다.
   - **MMD 모션(.vmd)** 도 같은 칸에 넣으면 됩니다 (MikuMikuDance 춤 모션).
     - A포즈를 T포즈로 바꾸고, 좌표계 차이와 다리 IK를 처리해 이 앱의 캐릭터에 맞게 변환합니다.
     - 팔이 몸에 너무 붙거나 벌어져 보이면 `extract_dance.py 파일.vmd --mmd-arm-angle 40`처럼 각도를 조정해 보세요.
     - 표정·카메라 모션은 아직 쓰지 않습니다.
     - 배포된 MMD 모션은 대부분 이용 규약이 있으니 지켜 주세요.
   - **부드럽게**: 0(끔)~4(최대). 2까지는 전체를 고르게 다듬습니다. 2를 넘기면 거의 멈춰 있거나 천천히 움직이는 부분은 훨씬 강하게 다듬어 떨림을 없애고, 빠른 동작은 그대로 살립니다.
4. **결과 확인**: 반복 재생, 움직임, 거울 영상 등을 설정하고 **춤 만들기**를 누른 뒤, **지금 춤추게 하기**로 바로 적용합니다.

## 살아 있는 느낌 (트레이 메뉴 → 반응)

- **마우스 쳐다보기**: 눈과 고개가 마우스 커서를 따라갑니다. 춤출 때는 살짝만, 포즈일 때는 더 많이 돌립니다. 커서가 한동안 멈춰 있으면 가끔 보기만 합니다. 눈도 자동으로 깜빡입니다.
- **클릭·쓰다듬기·들어 올리기 반응**
  - 머리 클릭: 웃으며 깡충
  - 몸 클릭: 깜짝 놀람
  - 빠르게 여러 번 클릭: 화냄
  - 머리 위에서 커서를 좌우로 문지르기: 쓰다듬기(눈 감고 좋아함)
  - 끌어서 옮기기: 춤을 멈추고 다리를 버둥거리며 흔들림, 내려놓으면 안심
  - **Alt + 끌기**: 손·발·가슴을 잡아 당깁니다. 손·발은 커서를 따라가고(팔꿈치·무릎이 자연스럽게 굽음), 가슴은 상체가 그쪽으로 기웁니다. 나머지 몸은 계속 춤춥니다. 놓으면 1초쯤에 걸쳐 부드럽게 춤으로 돌아갑니다.
  - **Alt + 끌기 후 Shift를 누른 채 놓기**: 그 자리에 고정됩니다. 여러 군데를 고정할 수 있고, 다시 Alt로 잡으면 풀려서 다시 움직일 수 있습니다. 트레이 **포즈 → 고정한 팔다리 풀기** 로 모두 풉니다.
  - 표정은 캐릭터 VRM에 해당 표정(happy, surprised, angry, relaxed, blink)이 있을 때만 바뀝니다.
- **가끔 작업표시줄 위를 산책하기**
  - 1~3분마다 몸을 돌려 작업표시줄을 따라 걸어가서, 다른 자리에서 다시 춤추거나 포즈를 취합니다.
  - 작업표시줄 위에 서 있을 때만 걷습니다. 높이를 바꿨거나, 화면에 비해 너무 크거나, 음악에 맞춰 춤추는 중이면 걷지 않습니다.
  - 걷는 중에 끌면 그 자리에서 멈춥니다.
- **산책 뒤 가끔 걸터앉아 쉬기** (기본 켜짐): 산책이 끝나면 가끔 작업표시줄 끝에 걸터앉아 20~40초 쉽니다. 다리를 흔들흔들합니다.
- **앉아서 춤추기 (상체만)** (기본 꺼짐): 걸터앉은 채로 상체만 춤추고, 다리는 흔듭니다.
- **캐릭터를 끌어서 창 위쪽 끝에 놓기** (Windows): 발이 창의 위쪽 끝 근처(약 40px 안)에 오게 놓으면 그 창에 걸터앉습니다. 그 창을 옮기면 따라가고, 창을 닫거나 최소화·최대화하면 바로 아래 작업표시줄로 내려옵니다. 다른 창에 가려진 끝에는 앉지 않습니다.
- **게임·전체 화면일 때 숨기기** (Windows, 기본 켜짐): 전체 화면 게임이나 영상이 캐릭터가 있는 모니터를 덮으면 캐릭터를 숨기고 그리기도 멈춥니다. 끝나면 다시 나타납니다. 숨어 있는 동안 트레이 메뉴 맨 위에 표시됩니다.
- **앞에 있는 창 위에 걸터앉기** (Windows, 기본 꺼짐)
  - 지금 쓰고 있는 창의 위쪽 끝(제목 표시줄)에 걸터앉아 춤춥니다. 창을 옮기면 따라갑니다.
  - 창이 최대화·전체 화면이거나, 너무 작거나, 화면 맨 위에 붙어 있으면 작업표시줄로 돌아갑니다.
  - 창에서 끌어내리면 그 창에는 다시 올라가지 않습니다(다른 창을 쓰면 그 창으로 갑니다).
- **앉는 자세** (트레이 메뉴): 쉬거나 창 위에 앉을 때의 자세. 그때그때 랜덤(기본), 다리 흔들기, 다리 꼬기, 팔짱 끼기, 다리 꼬고 팔짱, 뒤로 기대기, 무릎에 손, 턱 괴기. 앉아서 춤출 때는 다리 자세만 따릅니다. 다리를 꼰 자세는 다리를 흔들지 않습니다.
- **앉았을 때 높이 보정** (위치·크기 창): 엉덩이가 떠 보이면 + (아래로), 파묻히면 − (위로). 자동으로는 모델의 허벅지 두께를 재서 허벅지 아랫면이 창·작업표시줄 끝에 닿게 맞춥니다.
- 앉아 있을 때는 내린 다리가 보이도록 창이 바닥 아래로 늘어납니다. 그래서 다리가 작업표시줄 앞에 보입니다. **작업표시줄 뒤로** 가 켜져 있으면 다리가 작업표시줄에 가려집니다.
- **음악에 맞춰 춤추기 (PC 소리 듣기)**
  - PC에서 나오는 소리(유튜브, 음악 앱 등)의 박자를 알아내서 춤 속도와 박자를 맞춥니다.
  - 노래가 멈추면 원래 속도로 돌아갑니다. 포즈일 때는 박자에 맞춰 고개를 까딱입니다.
  - 소리는 박자 분석에만 쓰고, 저장하거나 밖으로 보내지 않습니다.
  - Windows 전용 기능입니다(시스템 소리 캡처). 기본은 꺼져 있습니다.

## 전용 툰 셰이더 (트레이 메뉴 → 보기)

캐릭터를 애니메이션 셀 느낌으로 그립니다 (기본 켜짐). VRM의 MToon 재질을 그대로 두고 그 위에 효과를 더하는 방식이라, 끄면 원래 모습으로 돌아갑니다.

- **또렷한 2단 그림자**: 밝은 면과 그림자의 경계를 선명하게 합니다. 그림자 색이 원래 색과 같은 모델은 자동으로 그림자 색을 만듭니다.
- **조명**: 그림자를 지우던 환경광을 줄이고, 빛을 약간 옆·위에서 비춥니다. MToon이 아닌 모델(기본 마네킹 등)은 원래 조명 그대로입니다.
- **얼굴**: 머리 뼈를 기준으로 구처럼 음영을 넣어, 고개를 돌리면 얼굴 그림자가 부드럽게 따라 움직입니다.
- **얼굴에 지는 머리카락 그림자**: 앞머리 그림자가 이마와 눈가에 집니다. 따로 끌 수 있습니다.
- **머리카락 광택 띠**, **피부의 따뜻한 그림자 색과 경계선**, **재질별 림라이트**
- **강도** 25~100%: 원래 MToon 모습과 섞는 비율입니다.
- 재질 종류(얼굴·머리카락·피부·옷·눈)는 재질 이름으로 짐작합니다. 변환 도구가 glTF 재질의 `extras.dancerToon`(`kind`, `lightmap`, `shadeWarm`)을 넣어 주면 그 값을 씁니다. 라이트맵은 G 채널로 그림자 쉬운 정도를 조절합니다.
- 캐릭터 만들기 창의 미리보기에도 같은 모습으로 나옵니다.
- **조명 설정 (얼굴·몸 밝기, 빛 방향)…** (보기 메뉴): 슬라이더로 직접 조절하고, 바로 적용·저장됩니다.
  - 부위별 밝기: 얼굴(눈 포함) 40~160%, 몸(피부·옷) 40~200%, 머리카락 40~160%
  - 몸 그림자 밝기 0~100%: 높일수록 몸의 그림자 쪽이 밝은 면에 가까워집니다(얼굴과의 차이가 줄어듦).
  - 주 조명 세기, 주변광, 빛 방향(왼쪽↔오른쪽, 0이면 정면), 빛 높이
  - **기본값으로** 버튼으로 되돌립니다. 부위별 밝기·그림자 밝기는 툰 셰이더가 켜져 있을 때만 적용됩니다.
- 밝기는 원신풍 화면처럼 맞췄습니다. 밝은 면은 텍스처 색이 거의 그대로 나오고, 그림자는 80% 안팎으로 밝게 유지됩니다.
- MToon 재질이 없는 캐릭터(일반 glTF 재질, Unlit 등)도 툰 모드에서는 같은 텍스처로 만든 MToon 재질로 바꿔 그려서 효과와 조명을 받습니다. 끄면 원래 재질로 돌아갑니다.
- **옷이 비쳐서 팔·몸이 보일 때**: 게임 계열 텍스처는 알파 채널에 투명도가 아닌 다른 데이터(발광 마스크 등)를 넣는 경우가 많습니다. 그 재질이 반투명으로 그려지면 옷이 비칩니다.
  - 옷·피부 재질 가운데 넓은 면적이 반투명인 것은 자동으로 불투명하게 그립니다.
  - 캐릭터 만들기 창 4번 **재질별 색** 목록의 **불투명** 체크로 재질마다 직접 바꿀 수 있습니다. 레이스·스타킹처럼 정말 비쳐야 하는 재질이면 체크를 끄세요.

## 고정 포즈 (춤 대신 가만히)

트레이 메뉴 **포즈** 에서 고르면 캐릭터가 그 자세로 가만히 있습니다. 숨쉬기처럼 아주 조금만 움직입니다.

- 기본 포즈
  - 서기: **편하게 서기, 허리에 손, 만세, 팔짱 끼기, 손 모으기**
  - 앉기(작업표시줄·창 끝에 걸터앉음): **걸터앉기, 다리 꼬고 앉기, 팔짱 끼고 앉기, 다리 꼬고 팔짱 끼고 앉기, 뒤로 기대 앉기, 무릎에 손 올리고 앉기, 턱 괴고 앉기**
- **사진으로 포즈 만들기**
  - 트레이 메뉴의 **포즈 만들기 (사진에서)…** 로 엽니다(춤 만들기 창의 ‘포즈’ 탭).
  - 사진(jpg, png, webp)을 넣으면 사진 속 사람의 자세를 알아내 그대로 따라 합니다.
  - 몸 전체가 보이는 사진이 가장 잘 됩니다. 다리가 안 보이면 다리는 서 있는 자세가 됩니다.
  - 셀카나 거울 사진은 **좌우 반전**을 켜세요.
  - 만든 포즈는 `<이름>.pose.vrma` 로 모션 폴더에 저장되고, 트레이 메뉴 **포즈** 에 나옵니다.
- **지금 포즈 저장** (트레이 **포즈** 메뉴): 화면에 보이는 자세 그대로 `내 포즈 N.pose.vrma` 로 저장하고 바로 그 포즈로 바꿉니다. Alt+끌기로 손발을 옮기고 Shift로 고정한 뒤 저장하면 원하는 포즈를 직접 만들 수 있습니다.
- 걸터앉는 포즈(허벅지가 앞으로, 엉덩이가 낮은 자세)에서는 다리를 흔듭니다. 음악이 나오면 박자에 맞춰 번갈아 흔듭니다.

## 내 그림으로 캐릭터 만들기

트레이 메뉴에서 **캐릭터 만들기 (그림에서)…** 를 누르세요.

1. **그림 고르기**: 전신, 정면, T/A 포즈인지 자동으로 확인해 줍니다.
2. **3D 모델 만들기** — 방법 세 가지 중 하나를 고릅니다.
   - **내 PC 그래픽카드로 만들기 (TripoSG / TripoSR)** — AMD도 됩니다
     - 처음 한 번 **준비하기**를 누르면 그래픽카드에 맞는 PyTorch와 생성 AI를 앱 전용 폴더에 설치합니다 (수 GB, 10~30분).
       - AMD는 AMD 공식 Windows용 PyTorch(ROCm 7.2.1, RX 7000·9000 시리즈)를 씁니다. 그래픽 드라이버 Adrenalin 26.2.2 이상이 필요합니다.
       - NVIDIA는 CUDA, 그래픽카드가 없으면 CPU(TripoSR만, 느림)로 설치합니다.
     - 1번에서 그림을 고르고 **3D 모델 만들기**를 누르면, 배경 지우기 → 3D 모양 → 색 입히기 → 뼈대 → 흔들림까지 한 번에 진행합니다.
     - **TripoSG**: 모양이 정교합니다. 색은 그림을 모델에 입히고, 뒷면은 테두리 색으로 채운 근사입니다.
     - **TripoSR**: 2024년 모델이라 모양이 더 뭉툭하지만 색까지 스스로 만듭니다.
     - 두 모델 모두 MIT 라이선스입니다. TripoSG 저장소에는 일부 코드가 Tencent Hunyuan 계열에서 왔다는 안내가 있습니다. Hunyuan3D 자체는 한국이 라이선스 지역에서 빠져 있어 쓰지 않습니다.
   - **A. 무료 웹 생성기 + 내 PC 자동 리깅 (그래픽카드 상관없음)**
     - Tripo나 Meshy 웹사이트에 그림을 올려 GLB를 받습니다.
     - 받은 GLB를 넣으면 뼈대는 **이 PC에서 자동으로** 넣습니다. CPU만 쓰고 약 15초 걸리며, AMD도 됩니다.
   - **B. 클라우드 GPU (TRELLIS + UniRig)**: 오픈소스이고, NVIDIA GPU를 빌려서 씁니다.
   - **C. VRoid Studio**
     - 얼굴, 머리카락, 옷까지 **슬라이더로 세밀하게** 직접 디자인하는 무료 프로그램입니다(코이카츠와 비슷).
     - VRM으로 내보내서 넣습니다.
3. **결과 가져오기**: `.glb` 나 `.vrm` 을 끌어 놓습니다. 뼈대가 없는 GLB는 자동으로 리깅됩니다.
   - 그림에 몸 일부가 없어서 모델도 정강이나 허리, 손에서 잘려 있으면, 관절을 모델 안으로 맞춥니다. 없는 부분의 뼈는 몸을 끌지 않게 해서 리깅이 깨지지 않습니다.
   - 상반신만 있는 모델도 됩니다. 이때 다리 뼈는 움직여도 보이는 것이 없습니다.
   - 자동 리깅할 때 **긴 머리카락**(등 뒤로 늘어진 부분)과 **치마**(골반 아래에서 다리와 떨어져 둘러진 부분)를 찾아서 흔들림 뼈를 넣습니다. 춤추거나 걷거나 끌어서 옮길 때 자연스럽게 흔들리고, 몸을 뚫지 않게 충돌 판정도 넣습니다. 끄려면 `make_character.py --no-springs`.
4. **확인 · 다듬기 · 적용**
   - 3D 미리보기와 춤 미리보기로 확인합니다.
   - 슬라이더로 **키, 머리 크기, 어깨 너비, 팔·다리 길이, 밝기**를, 재질별(머리카락·피부·옷…) **색**을 조정합니다.
   - 조정값은 원본 파일과 따로 저장되어 언제든 처음대로 되돌릴 수 있습니다. 라이브러리의 모든 캐릭터(VRoid 캐릭터 포함)에 쓸 수 있습니다.

## 기본 포함 에셋

권리 문제가 없도록 두 파일 모두 코드로 생성했습니다. 생성 스크립트는 `npm run gen:samples` 입니다.

| 파일 | 내용 |
|---|---|
| `assets/characters/mannequin.vrm` | 박스로 만든 VRM 1.0 휴머노이드 마네킹 |
| `assets/motions/sample-dance.vrma` | 120 BPM, 4초 길이의 제자리 춤 루프 (팔 펌핑 → 팔 들어 흔들기) |

## 개발

Node 20 이상이 필요합니다.

```bash
npm ci
npm start        # 앱 실행
npm test         # 창 배치 단위 테스트 + 캐릭터/춤 로딩·발 미끄러짐·루프 검사
npm run dist     # Windows용 exe 빌드 (Windows에서 실행)
```

다른 VRM/VRMA 조합이 깨지지 않는지 검사하려면 아래처럼 실행합니다.

```bash
node scripts/check-assets.mjs path/to/character.vrm path/to/motion.vrma
```

개발용 환경 변수입니다.

- `DANCER_SELFTEST=out.png`: 몇 초 뒤 창을 캡처해 저장하고 앱을 종료합니다. 대기 시간은 `DANCER_SELFTEST_DELAY` 로 바꿉니다(ms).
- `DANCER_FREEZE_T=1.5`: 춤을 해당 시각에 멈춥니다.
- `DANCER_USER_DATA=dir`: 설정과 라이브러리 폴더 위치를 바꿉니다.
- `DANCER_RECORD=dir`: 모션을 30fps PNG 프레임으로 렌더링한 뒤 종료합니다. 프레임 수는 `DANCER_RECORD_FRAMES` 로 정합니다. 추출 정확도 테스트용 영상을 만들 때 씁니다.

## 구조

- `src/main.js`: 투명 창, 트레이 메뉴, 라이브러리, 드래그, 화면 변화 감지
- `src/placement.js`: 작업표시줄 감지, 창 위치·크기 계산 (25~1600%, 높이 오프셋, 화면 밖으로 밀기·잘린 부분 처리)
- `src/placewin/`, `src/placewin-preload.js`: "위치·크기" 창
- `src/settings.js`: 설정 저장
- `src/studio/`, `src/studio-preload.js`: "춤 만들기" 창
- `src/pipeline-runner.js`: uv로 Python과 패키지를 자동 설치하고, 파이프라인 실행과 진행률을 전달
- `src/charstudio/`, `src/charstudio-preload.js`: "캐릭터 만들기" 창 (그림 확인, 만드는 방법 안내, 변환, 3D 미리보기, 다듬기)
- `src/renderer/customize.js`: 비율·색 다듬기 (`<캐릭터>.custom.json`, 앱과 미리보기가 같이 사용)
- `scripts/preview/`: 모델을 앞·옆·뒤에서 렌더링하는 개발용 미리보기 (Playwright)
- `src/preload.js`: 렌더러에 노출하는 IPC API
- `src/renderer/`: three.js + three-vrm 렌더링, 픽셀 알파로 클릭 통과 판정, FPS 제한
- `scripts/vendor.mjs`: 렌더러가 쓰는 라이브러리를 `src/renderer/vendor/`로 복사 (`npm start`·`npm run dist` 때 자동 실행)
- `scripts/make-samples.mjs`, `skeleton.mjs`, `dance.mjs`, `gltf-writer.mjs`: 샘플 VRM/VRMA 생성
- `scripts/check-assets.mjs`, `scripts/test-placement.mjs`: 테스트

## 알려진 한계 (MVP)

- 클릭 통과와 마우스 오버 판정은 Windows/macOS에서만 동작합니다. Electron의 마우스 이벤트 전달 기능이 Linux를 지원하지 않기 때문입니다.
- 작업표시줄이 위나 옆에 있을 때는 캐릭터가 화면 아래쪽 작업 영역에 섭니다.
- 전체 화면 게임이나 영상을 재생할 때 자동으로 숨기는 기능은 아직 없습니다. 트레이 클릭으로 직접 숨기세요.
